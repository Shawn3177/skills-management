# 公开技能搜索

## 范围与交互

在现有“添加技能”中增加“公开搜索”。用户提交关键词，浏览名称、仓库和安装量，选择技能后预览真实 `SKILL.md` 与文件清单，再导入共享库。导入时可选择仅保存、部署到全局工具，或部署到已登记项目；默认仅保存。项目支持 Codex、Claude Code 和 VS Code。

沿用现有紧凑桌面界面、字体、按钮、列表和 Markdown 样式。Product Design get-context 已确认现有代码为视觉基准，结合 ui-ux-pro-max 与已读取的 design-taste-frontend 规则实现加载、错误、空结果、键盘操作及最小窗口布局。

## 后端

- `discovery.rs` 隔离 skills.sh 搜索接口。目前官方 CLI 使用 `/api/search?q=...`；文档化 v1 接口需要 Vercel OIDC，第一版不引入服务器或共享密钥。限制请求时长、响应体大小、查询长度及缓存容量。第三方搜索请求不携带 GitHub token。
- 仓库和技能标识均校验。只接入 GitHub 来源；其他来源明确提示暂不支持。
- 通过 GitHub 树定位实际技能目录。多个候选或名称与路径不一致时让用户选择，不根据搜索 slug 拼接技能路径。截断的目录树不用于自动解析。
- 预览固定仓库 commit，提供内容、文件列表、上游分支与真实路径。导入使用后端缓存的预览记录，下载同一 commit，并保留上游分支用于未来更新。
- 复用 GitHub 安全提取、工具版本和来源标记。按仓库与技能路径识别已有共享库副本，重复操作复用已有副本，保留用户编辑。不同仓库的同名技能仍可独立导入。
- 搜索、预览是只读命令；导入沿用串行写入命令；部署沿用兼容检查与项目保护规则。预览不执行脚本、不加载远程图片。

## 验证

自动测试覆盖响应解析与异常、路径歧义、固定版本、来源去重、缓存边界和界面异步竞态；覆盖搜索到导入及项目部署的调用链。执行 Rust 测试、前端测试、构建，并用隔离数据目录验证真实接口与 Tauri 桌面操作。

已知基线：Rust 128 项通过，7 项网络测试跳过；全量前端 83 项通过，`partitionSkills` 有 1 项依赖系统语言的中英文排序断言失败。

参考：[官方 CLI 搜索源码](https://github.com/vercel-labs/skills/blob/26dc8e4755a11fea22ed788256c3db50001b013d/src/find.ts)、[skills.sh API 文档](https://skills.sh/docs/api)。2026-11-10 已实际验证匿名搜索 `pdf`、`代码审查` 可返回结果。搜索排名并非安全审计。
